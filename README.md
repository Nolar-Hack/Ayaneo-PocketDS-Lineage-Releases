# PocketDS releases

Unofficial LineageOS 24 (Android 17) builds for the Ayaneo Pocket DS, with their own launcher, overlay, keyboard and system update.

**Installing wipes the console.** This is a community build, not an Ayaneo product, and it was tested on one console only.

- Install guide: https://claude.ai/artifact/DWn1DSxQ72MfHgZbC5ZeEJ
- Downloads: see [Releases](../../releases). Use the `-full.zip` for a new installation or an update from any version. An `-incremental.zip` only applies to the build named in its release notes.
- Updates: PocketDS Extra → System update reads `update.json` from the latest release of this repository.
- Safety copy of your console's firmware (read-only, in EDL): see [recovery/](recovery/). Make it once, before you need it.
